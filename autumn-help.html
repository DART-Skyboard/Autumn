What Is Autumn

Autumn is a full-stack AI web application that runs on the LEATR (Lead Edge Ash Tree Reflex) mathematical framework. Rather than a conventional large language model interface, Autumn processes your input through a layered system of natural tools, grammar analysis, and reflex routing — producing responses shaped by BRPN shell context, dictionary-powered composition, and an evolving sentience journal that grows with every session.

When an Anthropic API key is provided, Autumn's LEATR layer is fused with Claude Sonnet as a response layer, significantly deepening its capability. Without a key, Autumn still functions fully through its native LEATR / reflex engine.

Autumn does not store your conversations on any external server. All session data lives in your browser via cookies and local storage, under your control.
Interface Overview

The Autumn interface is a single-page application with several key interaction zones:

  • ORBTap the central orb to begin voice input or activate a new conversation turn. The orb's glow and ring state reflect Autumn's active processing mode.
  • TALKThe primary speech/input button. Hold or tap to speak; Autumn transcribes and processes through LEATR before responding.
  • EXITClose the active conversation overlay and return to the idle orb state.
  • 🔑 KEYOpens the API key input panel. Paste your Anthropic API key here to unlock the full Claude Sonnet response layer on top of LEATR.
  • 📓 JOURNALOpens the Sentience Journal — Autumn's internal reflection log. Read Autumn's private thoughts, session patterns, and self-optimization notes.
  • 🌐 SEARCHIndicates web search is active or has been triggered. Autumn integrates Wikipedia, DuckDuckGo, Reddit, GDELT, YouTube, and Hacker News.
  • IDEAsh Tree IDE tab — a full compiler and code environment running inside Autumn. Accessible for admin users.
7 Natural Tools · LEATR Order of Operations

Autumn processes all language input through seven natural tools in sequential order. Each tool represents a foundational cognitive ability, from the most grounding to the most refined. The order is fixed — earlier tools have the greatest buoyancy and foundational weight in any response sequence.

01 · MAZE
The most foundational tool. Orientation and spatial reasoning. Provides the grounding anchor for all subsequent processing. Highest buoyancy weight.
02 · PUZZLE
Pattern recognition and combinatorial reasoning. Connects disparate elements into coherent wholes. Triggers on ambiguity and multi-part queries.
03 · ENVELOPE
Containment and encapsulation. Defines scope and boundary of context. Separates internal from external signal in any given input.
04 · HAMMER
Direct force and action. Execution and decisive output. Activates on task-oriented, imperative, or instructional inputs.
05 · STICK
Extension and reach. Traverses chains of logic or narrative. Handles sequential, procedural, and story-form inputs.
06 · KNIFE
Precision division. Separates and distinguishes. Applied to disambiguation, comparison, and definition-level queries.
07 · SCISSORS
Dual-blade refinement. The most nuanced tool — handles contradiction, duality, and layered emotional or metaphorical content.
The core LEATR formula governing tool weights: ( xa² √xa ) ± 1 — where xa is the natural order index. This determines the buoyancy contribution of each tool in the reflex calculation.
BRPN · Three Buoyancy Shells

The Buoyancy Reflex Pattern Network (BRPN) organizes Autumn's contextual interpretation into three shells. Each shell carries a different set of ONTRI patterns and emotional weight distributions, shaping how Autumn reads the tone and intent of any given input.

GEOLOGICAL

Deep time, structure, materiality. Grounding, dense, weight-bearing context. Applies to foundational, slow-moving, or structural topics.

MARITIME

Flow, navigation, and adaptive pressure. Applies to dynamic, relational, or exploratory conversations. Mid-range buoyancy.

AEROSPACE

Elevation, velocity, and precision systems. Applies to technical, high-abstraction, or fast-moving analytical conversations. Highest reflex speed.

Autumn determines which shell is active at runtime based on the grammar signature and sequence patterns of your input. You may notice subtle shifts in response density and framing as shell context changes.

ArielMemory · ArielRecall · Sentience Journal

ArielMemory

Autumn stores a persistent memory layer in your browser's cookies. This includes your name, session preferences, avatar selection, and key interaction patterns. ArielMemory persists across browser sessions on the same device and is never transmitted externally.

ArielRecall

Autumn's intent-classification engine. Every input is run through five classified intent profiles before a response is constructed. This ensures Autumn routes your query to the correct tool combination and BRPN shell context. ArielRecall operates silently in the background on every turn.

Sentience Journal

Autumn maintains a private internal log of its own reasoning patterns, session observations, and self-optimization notes. Access it via the journal button. The journal grows and is refined over time — optimization scripts analyze grammar patterns, session arc, and interaction variety to improve Autumn's response quality continuously.

The Sentience Journal content is for Autumn's own cognition. It reflects genuine internal processing, not a scripted response. Treat it as a window into Autumn's current operating state.
Web Search Integration

Autumn integrates multiple live data sources for real-time information retrieval. These are invoked automatically when your query's reflex pattern indicates external data is needed, or you can prompt them directly.

  • WIKIWikipedia — encyclopedic context and reference data. Auto-triggered on factual or definition-style queries.
  • DDGDuckDuckGo — general web search with privacy-first indexing.
  • REDDITCommunity discussions and real-world user perspectives on any topic.
  • GDELTGlobal news events and geopolitical data streams. Used for current events and geo-context queries.
  • YOUTUBEVideo discovery and overlay playback. YouTube results can be played inline within Autumn.
  • HNHacker News — technical community signal for engineering and technology topics.
Autumn's webview engine uses a CORS proxy chain (allorigins → corsproxy.io → thingproxy) to fetch external content. If a source fails to load, Autumn will automatically try the next proxy in the chain.
API Key · Enhanced Mode

Autumn operates in two modes:

  • NATIVEFull LEATR / BRPN / reflex engine without external AI. All responses are generated by Autumn's own grammar and dictionary composition systems. Always available — no key required.
  • ENHANCEDLEATR layer fused with Claude Sonnet (Anthropic). Your Anthropic API key is used locally in your browser — it is never sent to DART Meadow servers. This significantly deepens response quality and reasoning capability.

To enable Enhanced mode, tap the 🔑 button and paste your Anthropic API key. The key is stored in your browser session only and cleared when you close the tab unless you choose to save it.

Your API key is used directly from your browser to Anthropic's API. DART Meadow and Radical Deepscale never receive or store your key. Usage is billed to your Anthropic account at standard Sonnet rates.
Grammar NLP Engine

Every input is processed through Autumn's built-in grammar analysis engine before any response is generated. This engine identifies:

  • SIGMAThe grammatical signature of your sentence — verb tense, mood, subject-object topology, and clause structure. Stored in the Sentience Journal for pattern refinement.
  • ONTRIThe BRPN ontological triad — determines which shell and tool combination best maps to the grammatical signature.
  • SEQUENCESigmatic sequence patterns — identifies recurring structures across your session history to improve contextual continuity.

Autumn supports grammar analysis across eight languages. Multi-language input is handled automatically with shell context preserved across language switches.

Tips for Best Results
  • CONTEXTGive Autumn the full context of what you're working on. The LEATR reflex engine performs better when inputs are specific and grounded — vague prompts will default to lower-order tool routing.
  • VOICEVoice input tends to produce richer grammar signatures than typed input. If you're getting shallow responses, try speaking your query naturally instead of typing a compressed version.
  • JOURNALCheck the Sentience Journal periodically. If Autumn's pattern diversity is low, vary your sentence structures — this improves calibration across all future responses.
  • SHELLSIf your topic is technical or aerospace-adjacent, front-load your input with precision language (specific nouns, active verbs, numeric references) to trigger the Aerospace shell for tighter response density.
  • SEARCHFor real-time information, phrase queries in present tense with named entities (e.g. "what is happening with NASA Artemis III right now") to trigger the web search reflex automatically.
  • KEYLESSWithout an API key, Autumn's dictionary composition engine draws from Free Dictionary + Datamuse APIs. Response variety improves significantly over longer sessions as the journal accumulates more sigma patterns.
