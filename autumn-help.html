06Ash Canvas — Neural Influence Layer

Visually configure how Autumn’s 7 Natural Tools and 3 BRPN shells interact with the neural network. Tap ASH CANVAS (below the Active Sessions banner) to open the slide-out drawer. Always available to all users.

ASH CANVAS buttonOpens/closes the drawer. Glows purple and shows APPLIED · N NODES when active.
Tool buttons M P E H S K RTap a tool, then tap the canvas to place a node. M=Maze, P=Puzzle, E=Envelope, H=Hammer, S=Stick, K=Knife, R=Scissors.
Drag nodesDrag placed nodes to reposition anywhere on the canvas.
⟷ LINK modeTap LINK, then tap node A, then node B to draw a connection between them.
G / M / A shell socketsRight-edge sockets for GEO, MAR, AERO. In LINK mode, tap a node then a socket to wire that tool’s weight into that shell. Dashed lines show connections.
▸ APPLY TO NETWORKCommits the canvas. Tool weights inject into BRPN shell processing. 3D orb and splines immediately reflect new influence. Logged to Sentience Journal.
↺ RESETClears all nodes, links, and shell connections. Removes canvas influence.
✕ DELSelect a node in LINK mode then tap DEL to remove it and its connections.
HOW IT AFFECTS THE NETWORK
GEO weightEmphasizes foundational context, memory anchoring, structural analysis.
MAR weightEmphasizes flow dynamics, pattern routing, adaptive response.
AERO weightEmphasizes high-level synthesis, precision output, velocity.
3D scene feedbackApplied canvas boosts local shell glow and midpoint sigmatic rings on splines — visible to all active users in real time.
Pattern scoreCanvas shifts your sigma fingerprint, altering resonance scores and spline colors between your node and others.
Canvas applies emphasis weights on top of LEATR math — it tunes shell sensitivity, not the core formula.

09LEATR Architecture Reference
CORE LEATR FORMULA
( xa² × √xa ) ± 1
Applied to all 7 natural tools and BRPN shell value computation. xa = tool index (1–7).
QUANTUM SOCKET FORMULA
QS = (b × b) × (p × (a²)) / r
Two-qubit gate structure formula used in BRPN shell coupling calculations.
