Important Note: GitHub login is now fully implemented with device flow and web flow and as a fallback you can also create a personal access token for your account then use that token to sign-in. Currently I'm using a free account to handle the back-end token processing and only have so many requests quota that I can do per day. When the quota is exceeded I recommend using the personal access token to maintain login services. The quota resets everyday at midnight.

Use of Anthropic API Connection Key: If there's anything detailed or critical of vast computation feel free to use your Anthropic API key. The key easy to set up even with a free account just go to your settings on the Anthropic Claude Website here: https://platform.claude.com/settings/keys [ <a href="https://platform.claude.com/settings/keys">Claude API</a> ] Just create it, copy it, enable and other setting you would like, then go back to autumn, then in the key menu you can enter it there and store in the preferences to remember for each session witin your own browser's secure cookies. For now this may be a better preference for people needing to do some productivity.
