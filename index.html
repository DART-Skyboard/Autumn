◈ GITHUB TOKEN

A GitHub Personal Access Token (PAT) with repo → contents write access is required to read and write templates/autumn-logic.js.

Get one at github.com/settings/tokens → Generate new token (classic) → check repo.

Your token is stored in localStorage and will persist across sessions.

Data & Privacy Policy

Welcome to Autumn. Your personal chat history and information are stored locally in your browser cookies/storage and will not be sent to our servers. You may export or clear this data at any time.

However, to continuously evolve the LEATR Neural Network, we collect anonymized mathematical, parameter, and physics logic patterns based on your interactions. This usage pattern data (devoid of personal information) is synced securely to our cloud repository to optimize the core network architecture.
